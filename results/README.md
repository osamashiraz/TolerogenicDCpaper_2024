# results/

Outputs of `scripts/run_all.R`, named after the manuscript panel or table
they reproduce (e.g. `Fig1D_*`, `SupplTable_S5_*`).

- `figures/`: one PDF per panel. The PNGs are copies of the panels shown in
  the main README.
- `tables/`: Suppl. Tables S2–S7 (TSV), and cell counts per sample for the
  in-house and external datasets.

Rerunning the scripts overwrites these files. The Lin et al. 2020 panels
(`SupplFigS7_Lin2020_*`, `SupplFigS8_*`) appear only after that dataset is
set up (see the main README, step 4).
